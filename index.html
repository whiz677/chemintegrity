Methodology

Profile matching

Profiles are merged by normalized student name plus fuzzy school/local-section evidence. Same-name rows merge when the ACS local section matches, the school name is the same/roughly the same, or an unknown-location contest row has only one plausible known profile. Same-name rows with conflicting schools/sections stay split.

What counts in rankings?

Individual official/public-source rows count. Third-party recap rows are included by default but can be toggled off. Team rows are listed separately and do not inflate individual rankings unless the student’s name is explicitly published.

Still not pretending

Some contests did not expose full public tables through their official websites. Those are marked partial/source-tracked. This database is built to be extendable: add new official rows in data.js and the rankings/profile pages update automatically.
